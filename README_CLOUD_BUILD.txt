MSBTS 1.0 - Cloud Windows Builder
=================================

Dieses Paket kann komplett von einem Mac aus benutzt werden.
Der eigentliche Windows-Build laeuft in GitHub Actions auf einem
Windows-Cloud-Rechner.

Schnellstart:
  1. Inhalt in ein GitHub-Repository laden.
  2. GitHub -> Actions -> MSBTS Windows Installer.
  3. Run workflow.
  4. Artifact "MSBTS-1.0-Windows" herunterladen.

Ausfuehrliche Anleitung: ANLEITUNG_OHNE_WINDOWS_PC.txt
